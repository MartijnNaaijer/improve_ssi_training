# Data

## raw/

Copied unchanged from [ETCBC/ssi_morphology](https://github.com/ETCBC/ssi_morphology),
`data/` at commit `d05e2da61a8fba96ab7a03dc42c8208982c4a0e8` (2026-10-06).
Licensed under Apache 2.0 (`raw/LICENSE-ssi_morphology`).

| File | Content |
|---|---|
| `s12-in`, `s12-out` | Syriac, latest corpus version (18,146 lines, 255,339 words). **Gold standard.** |
| `s2-in`, `s2-out` | Syriac, the version used in Naaijer et al. (2023) and Chen et al.; kept for comparison only. |
| `t-in_con`, `t-in_voc`, `t-out` | Hebrew Bible (BHSA), unvocalised / vocalised / encoded; for auxiliary training. |

Format: `book<TAB>chapter<TAB>verse<TAB>text`, aligned word by word between `-in` and `-out`.
Nine references occur twice in `s12` because a verse is split over two lines;
`ssi.corpus.load_corpus` gives the second line the id suffix `#2`.

## splits/

Verse-id lists per split, generated by `scripts/make_splits.py` (seed 42):

- `random`: 80/10/10 random verse split.
- `heldout-<Book>`: the book is the test set; 10% of the remaining verses is dev.
